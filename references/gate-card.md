# lvsea-renwu 门卡与证据格式

用于 Gate 1 和 Gate 2 的短卡片。卡片必须让用户能在不打开全部日志的情况下判断是否继续。

## Gate 1：计划批准

```text
目标：
推荐路线：
领域 Skill：
主要产物：
数据口径与来源：
关键假设：
验收证据：
风险与回滚：
需要用户确认的外部动作：
```

## Gate 2：结果批准

```text
已完成：
验证证据：
未完成或警告：
可选修订：
本地文件：
拟执行的外部动作：
是否得到该动作的明确授权：
```

## 验收矩阵

| 标准 | 证据 | 结果 | 状态 |
| --- | --- | --- | --- |
| 交付物存在且可打开 | 绝对路径、文件大小或预览 |  |  |
| 内容满足用户目标 | 抽查、关键帧、测试或回读 |  |  |
| 事实/数据边界清楚 | 来源、校验或差异记录 |  |  |
| 分析可复现 | 输入文件、关键计算步骤或复现命令 |  |  |
| 无明显回归 | 针对性测试或独立审查 |  |  |
| 外部状态正确 | 远端 SHA、PR、部署检查 |  |  |
